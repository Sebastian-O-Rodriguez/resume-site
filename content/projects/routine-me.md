<p>Self-tracking only works when the record stays consistent — and it breaks the moment logging becomes another job. RoutineMe exists to remove that friction.</p>

<h2>The interesting problem</h2>

<p>Nutrition made the friction obvious. Searching for each ingredient and filling fields by hand is exactly what kills a habit. The answer was to let people describe a meal the way they'd say it, then turn that description into a structured entry for review before anything is saved.</p>

<h2>What I learned</h2>

<p>Natural language isn't a separate chatbot — it's one more input path into the same typed action system. The model proposes, the user confirms, and one write path enforces the rules. The hard part of an AI product isn't the model; it's keeping the user in control of what actually gets recorded.</p>
